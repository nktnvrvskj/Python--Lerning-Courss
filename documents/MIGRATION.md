# Переход с v0.1.0 на v0.2.0

Ветка `0.2.0` сохраняет структуру проекта (`src/`, пакет `src/ui/`, `assets/`,
`documents/`), но заменяет монолитное приложение на четыре класса.

## Соответствие файлов

| Было (v0.1.0) | Стало (v0.2.0) | Что изменилось |
|:--|:--|:--|
| `src/main.py` + класс `App(Interface)` | [src/main.py](../src/main.py) | точка входа только создаёт `TaskManager` и вызывает `run()` |
| `src/storege.py` (`load`, `save`) | [src/storage_manager.py](../src/storage_manager.py) | функции стали классом `StorageManager` с `add/update/delete/get` |
| `src/core.py` (консольные `task_add/red/delete`) | [src/task_manager.py](../src/task_manager.py) | CRUD-логика перенесена в фасад и работает с `Task` |
| `src/view.py` (экспериментальное окно) | [src/ui/Interface.py](../src/ui/Interface.py) | единая прослойка к tkinter |
| `src/ui/Button.py`, `Frame.py`, `Listbox.py` | те же файлы + `Entry.py`, `Label.py` | добавлены недостающие `App*`, приведён стиль |
| — | [src/task.py](../src/task.py) | новая модель `Task` с `to_dict/from_dict` |
| — | [src/ui/theme.py](../src/ui/theme.py) | цвета и шрифты в одном месте |

Удалены как устаревшие: `src/core.py`, `src/view.py`, `src/storege.py`.
`src/config.py`, `src/utils.py`, `assets/`, `documents/`, `oop/`, `src/cal.py`,
`src/logger.py` сохранены без изменений.

## Что осталось прежним

* Запуск из папки `src` и плоские импорты (`from ui.Interface import Interface`).
* Файл данных `src/task.json` (путь задаётся в `src/config.py`).
* Иконка `assets/icon.ico`.
* Разделение `src/ui/` на отдельные модули по виджетам.
* Старые задачи не теряются: `[{"name": "..."}]` читается и автоматически
  переписывается в новый формат при первом запуске.

## Что нужно знать при запуске

```bash
python3 src/main.py
```

Внешние зависимости больше не нужны: `PIL`/`psutil` для основного приложения не
используются (`psutil` остался только в учебном `src/logger.py`).

## Данные

Старый файл:

```json
["Купить хлеб", "Позвонить маме"]
```

или (промежуточный вариант):

```json
[{"name": "Купить хлеб"}]
```

Новый формат:

```json
[
  {
    "id": 1,
    "title": "Купить хлеб",
    "description": "",
    "status": false,
    "author": "—",
    "created_at": "2026-11-12T21:15:00"
  }
]
```

`StorageManager.load()` понимает оба старых варианта: строка превращается в
название, объект с `name` — в задачу. После загрузки файл сохраняется уже в
новом формате.

## Интерфейс

- Тёмная тема заменена на простую светлую: белые карточки, тонкие рамки и один
  акцентный цвет.
- Список задач стал компактным: в строке только статус и название.
- Справа появилась карточка подробностей: при клике по задаче показываются
  описание, автор, статус, дата создания и ID.
- Описание редактируется в многострочном поле, список получил полосу
  прокрутки.
- После создания задача остаётся выбранной и открытой в форме, поэтому её можно
  сразу доработать; кнопка «＋ Новая» очищает форму для следующей задачи.
